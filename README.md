## ✨ Engineering Features & Implementations

### 🎯 1. Interactive Dual-Perspective Project Filtering
The projects section is powered by a custom **ES6+ Filtering System** that allows recruiters to filter builds instantly between **Full-Stack/SDE** and **Data Science/Analytics** paths.
* **How it works:** Instead of hardcoded sections, the UI listens for filter triggers, applies elegant CSS3 transitions, and uses a performance-optimized `IntersectionObserver` to animate cards in and out.

### 📥 2. Dynamic, CORS-Safe PDF Resume Downloader
To ensure recruiters receive a personalized, dated file, the resume download button dynamically appends the download date to the filename (e.g., `YashPadme_resume_19thJul.pdf`).
* **The Challenge:** Modern browsers block custom filenames on external drives (like Google Drive) due to Cross-Origin Resource Sharing (CORS) security policies.
* **The Solution:** The "View" button points to a cloud-hosted Google Drive, while the "Download" button reads the local PDF as a **Binary Blob** from the local GitHub pages domain, applies the dynamic formatting in JavaScript, and saves it seamlessly.

### 💻 3. Interactive Codolio Competitive Profile
Competitive coding consistency is seamlessly integrated.
* Includes an embeddable, responsive **Codolio Visual Card** and custom social link mapping to showcase data structures, algorithms (DSA), and problem-solving trajectory in real-time.

### ⚡ 4. Lightweight Aesthetics & Performance
* **Custom Particles Engine:** Written in pure Vanilla JS to avoid heavy canvas-rendering libraries, animating lightweight backdrop elements with minimal CPU cycles.
* **Lazy Loading & Animations:** Sections fade-in on-scroll using a scroll-synchronized `IntersectionObserver` instead of bulky frameworks.
* **Zero Dependencies:** Form validation, responsive toggles, and UI interactions are engineered with zero third-party script bloat, yielding top-tier Lighthouse scores.
